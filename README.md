# ഭൂമി അളവ് & സ്കെച്ച്

ടേപ്പ് അളവുകളിൽ (വശങ്ങൾ + കോണോടുകോൺ) നിന്നോ GPS-ൽ നിന്നോ ഭൂമിയുടെ വിസ്തീർണവും സ്കെയിലിലുള്ള സ്കെച്ചും കണ്ടെത്തുന്ന ഓഫ്‌ലൈൻ മൊബൈൽ ആപ്പ് (PWA).

ആപ്പ്: https://shinebobby.github.io/bhoomi-alavu/

ഫോണിൽ Chrome-ൽ തുറന്ന് മെനുവിൽ (⋮) "Install app" / "Add to Home screen" അമർത്തുക.
